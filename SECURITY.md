# Security policy

Security reports are welcome for the current `main` of `LeonidaReforge/Leonida`. This is an experimental project;
there is no commitment to backport fixes to historical commits.

## Reporting

If **Report a vulnerability** is available on the [repository's Security tab](https://github.com/LeonidaReforge/Leonida/security),
use it to submit a private report. If it is not available, do not post the report publicly. Ask the current
maintainer, [@JokerDreamerCoder](https://github.com/JokerDreamerCoder), to arrange a private channel. If an issue
is the only way to reach the maintainer, post only a request for private contact, without vulnerability details.

In the private report, include the affected commit, environment, impact, and steps to reproduce with synthetic or
redistributable inputs. Omit credentials, game files, game-derived artifacts, and unrelated personal data even
in private reports. Do not attach exploit payloads or post reproduction details in public issues or PRs. The
maintainer will coordinate triage and disclosure with the reporter once contact is established.

For ordinary bugs, use [Issues](https://github.com/LeonidaReforge/Leonida/issues). Rights and provenance concerns
are covered by the [redistribution review](docs/redistribution-review.md).
